## Overview

This investigation analyzes a Windows Event Log Cleared alert generated by the EDR. The alert indicated that the Windows event logs may have been cleared, a technique commonly associated with anti-forensics. The objective was to determine whether the activity was malicious or a false positive.

| File Size | 437.5 KB |

---

- Checked the available logs for the investigation timeframe.

- Verified the file hash using VirusTotal and ANY.RUN.

---

## Investigation Steps

- Reviewed the alert details and associated host information.
- Verified that the source IP (172.16.20.3) belongs to the Exchange Server.
- Checked the available logs for the investigation timeframe.
- Analyzed the provided `powershell.exe` artifact.
- Verified the file hash using VirusTotal and ANY.RUN.
- Searched for additional indicators of compromise (IOCs).

---

## Findings

- No suspicious events were identified within the available logs.
- The executable had no malicious reputation on VirusTotal or ANY.RUN.
- No additional indicators of compromise were discovered.
- The absence of logs is consistent with the reported Event Log Cleared alert; however, there was insufficient evidence to confirm malicious log tampering.
